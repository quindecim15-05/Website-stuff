# StudySpace Product Context

**Purpose:** Provide a classmate-accessible, frontend-only exam preparation workspace grounded in eight uploaded learning materials.

**Audience:** Students preparing for DCIT 50, GNED 07, GNED 10 and PATHFIT 3 examinations. No accounts.

**Core journeys:** (1) Choose subject and topic → read Quick Summary/Detailed lesson → flashcards/practice; (2) configure subject/topic/mixed exam → take Practice or Mock exam → results; (3) return on same browser → resume saved exam or inspect history.

**Technical constraints:** React, Vite, TypeScript, React Router, Tailwind CSS, local static content and browser localStorage. No server, user upload, remote grading or synchronization. Timed mock exams use local deadline, not anti-cheat enforcement.

**Content evidence:** 8 supplied sources; source pages are included for local development but removed from public build by default until redistribution permission confirmed. GNED 10 Media coverage explicitly incomplete as reviewer states.

**Success criteria:** deterministic validated grading, reliable refresh recovery, accurate page-linked study notes, functional exam configuration and navigation, responsive and accessible presentation, safe static deployment.
